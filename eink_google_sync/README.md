# 电子墨水日历固件

当前稳定版：`2.6.1-serial-wifi-setup`

## 已实现的长期稳定机制

- 每次同步优先请求家中群晖 NAS 上的局域网中继（`api_config.h` 中的 `EINK_LOCAL_RELAY_URL`，程序见 `../nas_relay`）：NAS 在后台定时从 Cloudflare Worker 拉取数据，设备只走局域网，不受外网对 workers.dev 的干扰。NAS 连不上时（连接 3 秒、读取 10 秒超时），同一次尝试内自动改用 Cloudflare 中继。
- Google 同步在单次唤醒中最多尝试 5 次（本地网络会随机丢弃发往 workers.dev 的请求）。
- HTTP 读超时为 20 秒：中继通常 2 秒内返回，实时回源最多约 14 秒；超过 20 秒无响应即视为连接失效，换路径重试。
- 同步期间关闭 Wi-Fi 省电模式，避免刚连网时丢失 TCP 数据包。
- 同步重试间隔为 3 秒；两个固定地址在每次尝试间轮流作为首选。
- 每次重试前重新读取本地时间，避免跨午夜仍使用旧日期。
- HTTP 200 响应解密失败按临时传输错误重试，不触发认证失败校时。
- 认证失败时先重新进行 NTP 校时，再用新的时间戳、随机数和签名重试一次。
- 连续失败后的下一次唤醒采用 1 分钟、5 分钟、15 分钟退避。
- 最后一次成功日程保存在两个交替使用的 NVS 槽位中，并带版本、长度和校验和。
- 数据没有变化时不写 Flash；相同数据最多每 6 小时更新一次缓存时间。
- 每 15 分钟定时唤醒并同步成功后，都会执行一次全屏可见刷新；即使内容不变，也会更新顶部“同步时间”并出现电子墨水刷屏反馈。为避免深度休眠后局部刷新不可靠而漏显示新内容，固定采用全屏刷新。
- Cloudflare 中继优先连接两个固定地址，DNS 仅作为最后备用（本地网络对 workers.dev 的 DNS 解析被污染，例如解析到 108.160.172.208）。每条连接路径最多等待 6 秒；DNS 路径会在串口日志中输出解析到的 IP。
- 左侧区域为“记事本”，同步 Google Tasks 中名称完全为 `记事本` 的清单；最多显示 10 条，条目不会混入日程、计划日程或待办事项。
- 断电启动后如果云端暂时不可用，优先保留原有屏幕；时间可用时可用当天缓存重建页面。
- OTA 固件上传必须同时提供 SHA-256 校验文件。
- OTA 新版本只有在 Wi-Fi、NTP、Google 同步和缓存写入均成功后才会确认，否则自动回退。

## 更换 Wi-Fi

已保存的 Wi-Fi 可用时不会自动进入配网。更换网络时，设备需连接电脑 USB：在复位或上电后的 3 秒内通过串口（115200）发送一行 `portal`，设备会开启 `EInk-Calendar-Setup` 热点（5 分钟有效），用手机连接后选择新的 2.4 GHz Wi-Fi 并输入密码。定时唤醒不会等待该命令。

## 首次安装

这一版仍需通过 USB/Arduino IDE 烧录一次。开发板选择 `XIAO_ESP32S3`，使用当前可用的 COM 端口。

烧录成功并完成一次正常同步后，后续版本即可通过局域网 OTA 更新。

## OTA 更新

1. 按一次 XIAO 的 `RST`。
2. 设备同步成功后会开放两分钟维护窗口。
3. 在同一局域网打开 `http://eink-calendar.local/update`。如果主机名不可用，从串口日志查看设备 IP，再打开 `http://设备IP/update`。
4. 用户名为 `eink`；密码保存在本机私密文件 `api_config.h` 的 `EINK_OTA_PASSWORD` 中，请勿分享。
5. 同时选择 `release` 文件夹中的 `.bin` 和对应 `.sha256` 文件。
6. 校验通过后设备自动重启。新版本第一次同步成功后会取消回退标记。

OTA 页面只应在可信任的家庭或办公局域网中使用。维护窗口结束后 HTTP 服务会自动关闭。

## 生成 OTA 文件

完成 Arduino 编译后运行：

```powershell
& .\make_ota_package.ps1
```

脚本会在 `release` 文件夹生成 OTA 所需的固件和 SHA-256 校验文件。

## 关键串口日志

- `Google sync attempt`：当前同步尝试次数。
- `Relay source`：中继数据来源，取值为 `kv`、`live`、`stale` 或 `legacy`（旧中继未提供来源响应头）。
- `Sync diagnostics`：最后 HTTP 状态、尝试次数和耗时。
- `Persistent agenda restored/saved`：掉电缓存恢复或保存成功。
- `flash write skipped`：数据未变化，主动跳过 Flash 写入。
- `OTA firmware verified`：新固件已通过首次运行检查。
- `rolling back`：新固件检查失败，正在回退。
